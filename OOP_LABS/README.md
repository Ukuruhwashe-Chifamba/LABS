# OOP in Java Lab Manual: exercise solutions

One folder per lab (lab01 ... lab10), plus a reference solution to the Lab 11 mini-project (lab11_library).
Every file was compiled and run on JDK 21; outputs were checked.

Compile and run inside ONE lab folder at a time (class names such as Circle, Student and Rectangle
are reused across labs, so mixing folders causes clashes):

    cd lab05
    javac *.java
    java Zoo

Files that need input (lab07/SafeDivide, lab10/SaveLines) read from the keyboard.
Explanations for the "explain why" exercises are in comments inside the source files.
